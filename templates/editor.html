Narration Style
These instructions define HOW the story AI writes: its persona, prose style, pacing and role-play rules. World, plot and characters stay in the Story and Cast tabs — this is the writing style only. Back keeps your edits; Save Storyline stores them.
Using the built-in style
How it works
The built-in style is a complete writing style: the player keeps control of their character, the world reacts and pushes back, characters only know what they could know, plus prose craft and output format. Your custom text fully replaces it. Story Rules (Story tab) always win over conflicting rules here, and the perspective directive is appended automatically — don't write it yourself. Limit: 10,000 tokens (~40,000 characters), counted live below the editor.

Story Functions
Functions are in alpha and subject to breaking changes: behavior, settings and stored data may change as the feature evolves.
No functions added
How it works
  1. Functions are real tools the story AI can call while writing. Only functions you add here exist in this storyline's chats.
  2. Pick a mode to add a function: Off by default / On by default set how new chats start (players can switch it in the Story Hub). Always on locks it on. Remove takes it out of this storyline.
  3. Functions need a model that supports function calling. When a tool is unavailable, its guidance still appears but the AI is told not to fake tool results.
  4. Custom instruction replaces the platform's default guidance for that function. Keep it about WHEN the function should be used. Real game mechanics (combat formulas, economies, win conditions) belong in Game mechanics on the Extras tab, which the AI sees whenever functions are active.
Use Always on only when the story depends on the function. Otherwise prefer On by default so players keep the choice.
